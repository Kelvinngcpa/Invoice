# Invoice Generator (Next.js + TypeScript)

A modern, free invoice generation web app built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Features
- Live invoice preview
- Dynamic line items
- Multiple currencies
- Tax calculation
- Download as PDF
- Clean & responsive UI

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
